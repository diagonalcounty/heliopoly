Scenario

Seed formula: seed_i = base + i × stride. Same seed + experiment arms compare fairly. Up to 1 000 000 games per run (~200–400 g/s on a fast Mac → ~40–80 min at the cap). Long runs stay on this machine only.

Results

Rates = share of finished games won by that key (winner’s direction / propellant / seat / rocket). All-retro → backward ≈ 100%. Mixed → forward + backward ≈ 100%.
