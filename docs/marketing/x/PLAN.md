# Heliopoly marketing plan (lean)

Owner: Steve. Written 2026-10-16.

## Goal and metric
- **6 paid units a week**, measured only by paid units in the weekday sales digest (Apple Sales report). Price $3.99.
- Ramp ends Oct 28. The quota starts the week of **Oct 29**. Baseline: 0 paid units since Sep 23.
- Budget: about 1% of the weekly token pool. No paid ads or promotion without Jacob.

## Channels, ranked by expected sales per token
1. **App Store page** (promo text, keywords, subtitle, screenshot order). Cheap, and it reaches people already searching. Promo text changes go live without review. See `aso-ideas.md`.
2. **X (@diagonalcounty)**. Posts from `queue-*.md`, written in one weekly batch. Browser time is only for posting.
3. **heliopoly.live**. The free browser version already has an App Store button. Only small copy tweaks, and only if the digest shows a lift from it.

## Cadence
- X posts **Mon / Wed / Fri** from the current queue file. Pin the launch post.
- **2–3 replies a day** under #indiedev, #screenshotsaturday and board-game posts. Replies should be useful, not ads.
- Monday check-in to Jacob: one line on what shipped, what it cost, and paid units.

## Steve can do without asking
- Routine X posts and replies: gameplay, screenshots, dev logs, handbook jokes, and fixes once they are live.
- Drafting App Store text proposals and queue files in this folder.

## Needs Jacob first
- Any price change or sale.
- Any App Store submission or listing edit (promo text, keywords, subtitle, screenshots).
- Any post about real people (family, testers, other devs) or any new claim that isn't in the listing or handbook.
- Spending money.

## Copy rules
- Facts come only from the live App Store description and `src/handbook/content.ts`.
- 2–6 pilots means **you plus AI**. It is not pass-and-play.
- Readers include a 9-year-old fast reader. Give a plain clue for any hard word in the same line.
- Never mention build tooling, wrappers, or anything off-game.

## 4-week checkpoint (Nov 13)
- Compare paid units for Oct 16 – Nov 12 against the zero baseline.
- If X has moved no sales, drop to one post a week and stop doing replies. Keep whatever ASO change lines up with a lift.
- If nothing has moved, bring Jacob one price test or one screenshot test to decide on.
