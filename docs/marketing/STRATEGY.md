## Strategy (90 days)

### 1. Product-led store surface (primary)
Apple Search + product page is the paid conversion surface. Every ship carries:
- One sharp promo (Angzarr-only; no `⍼` in promo/subtitle)
- Quirky Mainline bullets + Lab cruise bullets
- GitHub contribute CTA
- Screenshots that show `⍼` and Lab when possible

**1.3.1** is the first train with Bot Evolution + Lab in the binary + this copy.

### 2. Measurement loop (non-negotiable)
- Pull sales daily when published (~7am CT lag)
- Weekly digest: units, proceeds, vs 6/week target
- If a week < 3 units → change one lever (promo line, screenshot order, What’s New hook) — not ten at once

### 3. Distribution (secondary until connected)
Until a social connector exists, distribution is:
- App Store organic + direct link sharing
- GitHub / heliopoly.live as open-source proof
- Jacob-forwardable one-liners Steve drafts on request

**Week-1 unblock:** connect **X** (or Postiz) so Steve can post clerk-voice drops without a new bot.

Content pillars once posting works (1–2×/week, not spam):
1. Angzarr / ledger one-liners  
2. Lab cruise clips (Bot Evolution, etc.)  
3. “Only on the Mainline” Tesla / feral lines  
4. Open-source: ship notes + “file an idea on GitHub”

### 4. When to spin a marketing bot
Create a separate bot **only if**:
- Social cadence ≥3 posts/week with replies/engagement work, **and**
- It starts delaying ASC / review / sales ops

Until then Steve owns strategy + execution. Chiefly stays product-intent, not growth owner.
