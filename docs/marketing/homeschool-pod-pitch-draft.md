## Internal persona (staff only)

**Who we write toward:** adults facilitating 2–6 kids on a shared device; care about space + economics literacy; hate worksheet apps; will tolerate quirky clerk/Angzarr world.

**Smell test for any public line:** Would this still work if we never say “homeschool”? If it needs the word, cut it.

**Useful internal questions (not in-product copy):**

- Does the Ops Manual teach buy / leave / refuel without a teacher script?
- Does scarcity (fuel vs cash) show up in the first 20 minutes?
- Would a facilitator send a friend the App Store link without cringe?

**Internal framing that passed review (not for store):**

> Parents can use this to train kids on space and economics — if they can survive the ledger.
